# Additional ten seed synthetic experiments

**Supplementary study, not the required provided-trace evaluation.** D's generated workloads are used to explore cache behavior and the admission filter. For the main assignment results, open [evaluation/](../../evaluation/).

| Dimension | Synthetic study |
|---|---|
| Workloads | Repetitive, sequential, mixed and scan pollution, generated by D's seeded workload rules |
| Seeds | 0–9, ten generated traces per workload |
| Capacities | 100 KiB, 500 KiB, 1 MiB, 5 MiB and 10 MiB |
| Variants | FIFO, LRU, LFU, CUSTOM and CUSTOM_NOADM |
| Coverage | 1000 runs, 100 aggregate rows and 40 saved traces |

## Preserved material

- [runs.csv](runs.csv): individual seeded runs.
- [summary.csv](summary.csv): means and sample standard deviations over ten seeds.
- [d_compatible.csv](d_compatible.csv): D's original rounded comparison schema.
- [config.json](config.json) and [traces/](traces/): original provenance, parameters and exact generated inputs.
- [findings.md](findings.md) and [figures/](figures/): synthetic workload analysis and four original PNG/SVG figure pairs.

CUSTOM_NOADM disables the Custom admission gate while retaining its scoring and frequency rules. This is an extra ablation; the primary 72-run matrix contains only four policies. In the synthetic plots, shading is one sample standard deviation across seeds, not a confidence interval for the fixed instructor traces.

All historical numerical files and configurations are unchanged. These generated inputs must not be described as the instructor-provided workloads. Reproduce into a fresh local directory:

```bash
python3 -m experiments.run --output-dir results/my_synthetic_matrix
python3 -m experiments.plot --results-dir results/my_synthetic_matrix --output-dir results/my_synthetic_figures
```

See [HOWTO](../../HOWTO.md) and the [experiment guide](../../experiments/README.md) for options.
