A–E aliases and compared all **15 × 10 = 150** expected fields numerically

For the matrix, the original 40 traces matched all 40 hashes and counts in

and requested bytes across all policy/capacity combinations. The per-run
hit/miss, byte-hit, mean response, and origin-byte formulas and all 100

recalculated and matched. For a visible sample, the LFU 100 KiB ten-seed

## How A can repeat the checks

In a separate worktree at `3dfee73`, run the default batch command with a
**new** output directory, then compare its `runs.csv`, `summary.csv`, and
`d_compatible.csv` to the tracked
`results/experiments/d_reproduction/` files with `cmp`. With Python 3.14.5,
its `config.json` also matches the original config above byte for byte.
In a separate worktree at `104e379`, run the LFU reference command with a
new output directory. Its four output files match the original reference
files byte for byte. `shasum -a 256` can verify the hashes in the table;
the original CSVs and traces are in the linked Drive package.

The exact historical Git HEAD cannot be inferred from configs that omit a
commit field. This record names matching source snapshots and reports the
fresh replay results, without changing either original config or claiming
that the November 23 verification was the November 16 execution.
